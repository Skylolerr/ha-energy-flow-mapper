# Energy Flow Mapper

Not another energy card – a visual editor that maps your sensors into the Home Assistant
energy dashboard.

Energy Flow Mapper adds an admin panel to Home Assistant where you can see and edit the
energy dashboard configuration as a tree: which device is included in which, which
energy sensors are not used yet, and how much consumption is not tracked by any
individual device.

> **Status:** under development, not released yet. See [SPEC.md](SPEC.md) for the plan.
